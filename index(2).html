Features

Everything You Need,
Nothing You Don't

Built for security professionals who value privacy and speed.

🔒

Privacy-First

All data stored locally via IndexedDB (Dexie.js). No server required. API keys stay in your browser's localStorage. Fully offline-capable once loaded.

🤖

Multi-Model LLM

8 providers supported — Anthropic, OpenAI, Google, NVIDIA NIM, Groq, Moonshot, Z-ai (GLM), Minimax. Bring your own key, test connections, and switch models per task.

📊

CVSS v3.1 Calculator

Full FIRST.org-compliant scoring with all base metrics (AV, AC, PR, UI, S, C, I, A). Color-coded severity badges and vector string generation.

📝

Cybersecurity Templates

Pentest reports, CTF write-ups, and lab walkthroughs — plus track-scoped templates for cybersecurity, software dev, and DevOps/cloud.

📤

Export & Share

Markdown export that's version-control friendly. Export history tracking per project. PDF export coming soon.

☁️

Optional Cloud Mode

Extend with Supabase for auth, cloud storage, and streaming AI endpoints. PostgreSQL with Row Level Security — or stick with 100% local.

Built-In Vulnerability Scoring

FIRST.org-spec compliant CVSS v3.1 calculator with every base metric. Attach severity badges to findings with one click.

  • ✓ Full metric scoring: AV, AC, PR, UI, S, C, I, A
  • ✓ Color-coded severity badges
  • ✓ Vector string generation (CVSS:3.1/AV:…)
  • ✓ Quick presets for rapid assessment
  • ✓ Vector-to-metrics parser for importing scores
